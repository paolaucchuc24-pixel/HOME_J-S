# Control del hogar con IA

## 1. Nombre del proyecto

**Control del hogar: Aplicación móvil inteligente para la administración de productos y gastos personales.**

## 2. Descripción del proyecto

Control del hogar es una aplicación móvil diseñada para ayudar a las personas a organizar y administrar mejor los productos y recursos que utilizan diariamente. Permite registrar productos, controlar las cantidades disponibles, consultar fechas de caducidad, llevar un registro de compras y supervisar los gastos realizados.

Además, integra inteligencia artificial para analizar los hábitos de consumo, estimar cuándo podrían agotarse los productos y generar recomendaciones que ayuden a planificar las compras, evitar gastos innecesarios y reducir el desperdicio.

La aplicación será desarrollada con React Native y Expo, utilizando la arquitectura MVVM y un backend en FastAPI conectado a un modelo de inteligencia artificial.

## 3. Planteamiento del problema

En la vida cotidiana, muchas personas tienen dificultades para administrar correctamente los productos y recursos que utilizan en sus hogares. En ocasiones, no llevan un control de los productos que tienen disponibles, olvidan las cantidades que necesitan comprar, desconocen cuánto gastan y dejan que algunos productos caduquen antes de utilizarlos.

Esta falta de organización puede provocar compras innecesarias, desperdicio de alimentos y un mal manejo del presupuesto personal o familiar.

Ante esta situación, surge la necesidad de contar con una herramienta que facilite el control de los productos, las compras y los gastos. Por ello, se propone desarrollar Control del hogar con IA, una aplicación móvil que permita organizar esta información y utilizar inteligencia artificial para analizar los hábitos de consumo, estimar las necesidades de reabastecimiento y ofrecer recomendaciones que ayuden a administrar mejor los recursos.
